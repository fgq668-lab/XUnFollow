# 隐私说明

XUnFollow 的默认设计是不收集用户数据。

- 关系名单、互关缓存（稳定 X ID 与用户名）、回复候选、草稿、人设、提示词、目标、处理状态、每日进度和费用检查点均保存在应用数据目录下的本机 SQLite 数据库。
- TwitterAPI.io 和 DeepSeek 官方 API Key 保存在本机 XUnFollow SQLite 数据库内，不上传到 XUnFollow 的服务器，也不包含在进度导出文件中。数据库未额外加密；能读取该电脑用户数据的人或软件可能读取 Key。
- 应用不要求邮箱、手机号、X 登录或自建账户。
- 应用不运行分析 SDK、广告 SDK、远程遥测或行为追踪。
- Provider 同步和帖子搜索由用户主动发起，关键词、搜索条件会直接发送到 TwitterAPI.io。
- 生成回复/创作草稿时，用户选择的素材、人设及相应提示词会直接发送到 DeepSeek 官方 API。创作还会发送选定主题、用户主动填写的真实语气样稿，以及同一批已生成草稿的开头（最多30字）和结尾（最多20字，最近12条），用于减少句式重复；不会发送其他批次的历史。语气样稿只作提示词参考，不由本应用用于训练模型。XUnFollow 不运营中转服务器。
- 截图二次创作由用户主动粘贴、拖入或选择文件；仅在点击生成后，把处理过的截图发送给 DeepSeek 官方 `deepseek-flash`。请先遮挡敏感信息。原图在本机数据库临时缓存以支持手动续传，完成/结束本轮后清理缓存记录，草稿与用户填写的来源链接仍保留。缓存清理不等于安全擦除，SQLite/WAL/备份中可能留有残迹；请保护应用数据目录。
- 单条打开或复制草稿时，仅对应草稿会写入系统剪贴板；多开页面不覆盖剪贴板。截图粘贴仅处理用户主动粘贴事件中的图片，不后台读取剪贴板，也不读取 X 登录态。
- 创作的粘贴预览与复制采用同一份本机纯文本排版，保留分段空行、去除展示用 Markdown 标记；旧草稿的原始正文不会因预览或复制被改写。措辞提醒是关键词建议，不是AI检测或内容真实性判断。
- 单条「改得更口语」仅在确认费用后，把该条原文、来源文本、人设、提示词和语气样稿发送到官方 DeepSeek；不重新搜索、不操作 X。成功替换前将旧正文和标题保存在本机版本记录，可免费恢复；恢复会覆盖当前正文修改。失败保留原稿，仍可能计入本次 API 费用。
- 「放弃全部未发布草稿，重新生成」需要明确确认：旧稿只移到本机「已跳过」，未删除，可恢复；已发布记录不变。新请求失败或取消也不自动删除旧稿。
- 参考博主的读取由用户确认费用后发起，只向 TwitterAPI.io 发送公开用户名，每次只读一页。合格的中文原创文本、公开互动数、来源链接、采集时间和参考规则缓存在本机 SQLite；不采集私信、登录态或图片。基础过滤不保证移除所有不合适内容。生成时，选中博主每人最多6条文本片段（各最多800字）和规则发送到官方 DeepSeek，仅用于当前提示词参考，不由本应用训练模型。旧缓存不会自动刷新，读取中断不自动重试，计费不确定记录保存在本机。每轮创作冻结所选参考，之后修改规则只影响新的生成。
- 创作排期和进度保存在本机。开启提醒后，在应用运行期间向系统提交本机通知；通知不包含正文/图片。导出的日历包含标题与发布时间、不含密钥或截图，请妥善保存。

导出功能由用户主动触发。导出的文件可能包含关系处理历史，请自行妥善保存，不要上传到公开仓库。
